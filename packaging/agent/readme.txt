IT SUPPORT TOOLKIT - CÀI LOCAL AGENT CHO EDGE ADD-ONS (WINDOWS)
==============================================================

Gói này KHÔNG tải lên Edge Add-ons. Extension trên Edge Add-ons không
được phép chạy CMD hoặc cài chương trình Windows.

1. Cài IT Support Toolkit từ Edge Add-ons.
2. Mở edge://extensions/ và sao chép Extension ID của bản vừa cài.
3. Giải nén toàn bộ ITSupportToolkit-Agent-Windows.zip.
4. Chạy Install.cmd trong thư mục vừa giải nén, dán ID khi được hỏi.
5. Tải lại extension trong Edge rồi thử Ping.

Nếu máy đã cài Agent cho ID cũ, bộ cài giữ ID cũ và thêm ID mới.
Không cần quyền Administrator, Node.js hoặc Go. Agent chỉ chạy khi
extension yêu cầu; không cài service hay mở cổng mạng.

Bộ cài chưa ký số. Chỉ tải từ GitHub Release chính thức.
